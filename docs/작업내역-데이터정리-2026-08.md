## 1) 크롤 게이트 (유입 차단) — `b06001f`

`crawl-wikipedia-folklore.mjs`의 `isCreatureArticle`에 `looksNonCreatureSubject()` 추가.

**핵심 설계 (오차단 방지):**
- **첫 계사(copula: is/was a/an/the) 보어만** 검사 → 진짜 생물이 종속절에서
  "is the word for corpse"(ro-langs) 같은 표현을 써도 안 막힘
- soft 장소명사(lake·forest·mountain·stone)는 뒤에 생물어(monster·spirit·god·figure)가
  오면 통과 → 진짜 "lake monster·mountain god" 보호
- term/word는 뒤 6단어 안에 생물어 있으면 통과 → Knucker("water dragon") 구제
- 형용사 스킵이 전치사구("of the river Ganges")를 파고들지 않게 차단 → 강가 여신·Kek 구제
- 실존인물은 날짜·왕조 근거 있을 때만 차단 → 신화 왕·영웅 보호

**검증 (재실행 가능):**
- `node scripts/test-noncreature-gate.mjs` → 재현 테스트 (reject 21/21 · pass 15/15)
- `node scripts/regress-gate.mjs` → 기존 전체 데이터에 게이트 돌려 오차단 후보 리포트

## 주의사항 (마이그레이션 후 이어받을 때)

1. **데이터 정본은 `lib/folklore-data.ts`의 `FOLKLORE_DATA` — 한 줄짜리 거대 JSON 리터럴**이라
   git 자동 병합이 안 된다. 로컬 수정은 반드시 목록 기반 스크립트로 하고,
   원격이 앞서 있으면 `git reset --hard origin/main` 후 스크립트 재적용 → 커밋 → 푸시를
   한 체인으로 (중간에 `next build` 넣으면 그 사이 봇이 또 푸시함).
2. 크레딧 나가는 작업(이미지·아티클 AI 생성, `reclassify-types.mjs`의 OpenAI 호출)은
   대표 건별 승인 대상.
