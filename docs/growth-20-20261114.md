# 검색 유입 페이지 20개 개선

대상 URL은 `content/growth-campaign.json`에 고정했다. 검색 노출이 있었던 상세 18개와 한국어 한국·영문 자메이카 목록 2개다. 방문자 수와 계정 인사이트 기준선은 공개 저장소 밖에 보관한다.

상세 14개에 출처·확인 범위·판본 차이·독립적인 창작 질문을 새로 작성하고, 기존 영문 4개에는 검색 제목과 독자 질문을 보완했다. 해모수의 뱀 분류, 게리온의 전승 지역 혼동, 단일한 능력 목록으로 표현하던 불확실한 자료를 편집 계층에서 교정했다. 정본과 번역 데이터는 변경하지 않았다.

선정한 상세 페이지는 제목과 첫 설명을 그림보다 먼저 보여준다. 관련 존재와 국가별 목록, 한국어 작업실 또는 영문 무료 샘플로 이동할 수 있다. 새 국가 안내는 판본과 출처를 읽는 순서를 제안한다. 영문 자메이카 페이지의 목록은 확인한 Duppy와 Rolling Calf로 제한한다. 기존 수집 목록에는 다른 카리브 국가의 존재가 혼재했기 때문이다. 원본 데이터나 타 언어의 항목은 삭제하지 않았다. Ghana의 Anansi 항목은 비교 대상으로 지역을 명시해 연결한다.

`growth_page_view`와 `growth_next_click`은 campaign, page, source, target만 기록한다. 검색어·사용자 입력·전체 referrer URL을 보내지 않는다. Threads 링크에는 `utm_source=threads`, `utm_medium=social`, `utm_campaign=growth20_20261114`를 쓴다. QA 시 `growth_qa=1`로 이 두 이벤트를 제외한다. 루트의 기존 페이지뷰 측정은 별도이므로 배포일 브라우저 검증은 성장 성과에 포함하지 않는다.

검증: 편집 페이지 회귀 검사, 20개 실제 React 렌더·메타데이터·출처·관련 대상 검사, 유입 및 클릭 측정 검사, TypeScript, 변경 TSX/TS 파일 ESLint, webpack production build. Chrome에서 한국어 상세와 영문 국가 안내의 390px 화면, 가로 넘침 없음, 질문 펼치기를 확인했다.

성과는 배포 후 완료된 기간으로 비교한다. Threads 조회수와 사이트 방문자를 구분하고, 검색 반영 지연과 국가·유입원 변화를 함께 본다. 당일 자체 점검만으로 실제 방문자 증가를 주장하지 않는다.
